# GTD Planner

A small Getting Things Done planner built around David Allen's workflow:

1. **Capture** everything that has your attention.
2. **Clarify** what it means and what the next action is.
3. **Organize** actions, projects, waiting-for items, calendar and reference.
4. **Reflect** with a weekly review.
5. **Engage** with the right action for your context, time and energy.

## Run

```bash
npm start
# open http://localhost:4173
```

## Test

```bash
npm test
```

The app is dependency-free and stores data in the browser's `localStorage`.
